## 🎯 Hakkımda

**Maden Yüksek Mühendisi** formasyonundan gelen **analitik modelleme, jeodezik hesaplamalar ve endüstriyel matematik** altyapısını; modern full-stack web mimarileri, gömülü sistemler (IoT), veri bilimi ve kurumsal yazılım mühendisliğiyle harmanlıyorum.

Endüstriyel maden rezerv modellemelerinden gömülü robotik sistemlere, .NET 8 MVC kurumsal platformlarından makine öğrenmesi tabanlı borsa tahminleme motorlarına kadar uçtan uca, yüksek performanslı ve test edilmiş yazılımlar geliştiriyorum.

> *"Karmaşık mühendislik ve veri problemlerini; sade, güvenli ve %100 test edilmiş mimariler ile çözüyorum."*
